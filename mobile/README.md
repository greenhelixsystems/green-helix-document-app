# Mobile editor (web app)

This folder is the Green Helix Document Editor packaged as an installable web app. It is generated by `python build/build.py` and published to GitHub Pages by `.github/workflows/pages.yml`, so you should not edit it by hand.

**Live address:** <https://greenhelixsystems.github.io/green-helix-document-app/>

## Install on a phone or tablet

- **iPhone / iPad (Safari):** open the address, tap Share, then *Add to Home Screen*.
- **Android (Chrome):** open the address, open the menu, then *Install app* or *Add to Home screen*.
- **Computer (Chrome or Edge):** open the address and use the install icon in the address bar.

After the first visit the editor works without a connection. When you are online it checks for a newer copy each time it opens.

## Privacy

Everything happens on your device. The page only downloads itself; documents, images and files you add are never sent anywhere. Documents are saved to your downloads, the share sheet, or (on a computer) the file you pick.

## Hosting it yourself

Copy this folder to any web server that serves files over HTTPS. All links inside are relative, so it works from a sub-folder. In your own fork, enable GitHub Pages with *Settings, Pages, Source: GitHub Actions* and the workflow publishes it. (In a fork, replace the Green Helix name and logo; see [NOTICE.md](../NOTICE.md).)
