# Example: a research report in the 1.2 report style

Invented example data showing the presentation features added in Helix 1.2:

- a title area with a small line above the title, key-fact pills under the subtitle and a large title;
- a sticky section bar instead of a contents box;
- stat tiles, numbered option cards with coloured tags, status chips in a table;
- Danger and Success callouts;
- a sources block grouped by topic, with the date each source was read;
- AI Notes that point the next assistant at the options and protect the hard limits.

Open `Riverside-Garden-Outreach-Options_v1.helix.html` in any browser. Rebuild it with `python examples/research-report/make.py`.
